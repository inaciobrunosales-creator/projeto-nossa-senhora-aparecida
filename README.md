# Site Nossa Senhora Aparecida — 12 de outubro

Projeto acadêmico de desenvolvimento web que apresenta informações sobre Nossa Senhora Aparecida, a história do encontro da imagem, o Santuário Nacional e a celebração de 12 de outubro.

## Funcionalidades

- Navegação por seções da página.
- Carrossel de imagens.
- Cards informativos.
- Perguntas frequentes em formato de acordeão.
- Pesquisa de conteúdo dentro da página.
- Layout responsivo para computadores e dispositivos móveis.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.8
- Font Awesome Free 7.3.1

## Como executar

1. Faça o download ou clone este repositório.
2. Mantenha a estrutura de pastas apresentada abaixo.
3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências ou executar um servidor para visualizar a página localmente. Também é possível abrir a pasta no Visual Studio Code e usar a extensão Live Server.
